# Actividad-POO
## Sobreescritura de métodos
Es cuando una clase hija reemplaza un método que heredó de su clase padre. El método tiene el mismo nombre, pero la clase hija lo hace a su manera.

*Ejemplo:* Imagina que la clase padre Vehiculo tiene un método describir() que dice "soy un vehículo", eso es algo muy genérico que puede usar cualquier vehiculo. El Carro debería decir algo más específico como "soy un carro con 4 puertas".


## Parámetros posicionales
Son los parámetros normales. Se llaman posicionales porque el orden importa. El primero que defines es el primero que pasas, el segundo es el segundo, y así sucesivamente. Si cambias el orden al llamar el método o constructor, el programa se rompe o da resultados incorrectos.

*Ejempl:o* Para ubicar un punto en un mapa, utilizas un sistema de dos parámetros posicionales; Latitud y Longitud. Si dices (4.57, -74), el primer número es siempre la latitud y el segundo la longitud. Si los inviertes, marcarás un punto completamente distinto en el océano.
