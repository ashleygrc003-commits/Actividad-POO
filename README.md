# Actividad-POO

## Sobreescritura de métodos
Es cuando una clase hija reemplaza un método que heredó de su clase padre. El método tiene el mismo nombre, pero la clase hija lo hace a su manera.
Imagina que la clase padre Vehiculo tiene un método describir() que dice "soy un vehículo", eso es algo muy genérico que puede usar cualquier vehiculo. El Carro debería decir algo más específico como "soy un carro con 4 puertas".
